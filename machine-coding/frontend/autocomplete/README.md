# Autocomplete — Build-It-Yourself Machine Coding Tutorial

**You write all the code.** The files contain only a numbered step-by-step
guide in comments: design questions to answer first, a ✅ CHECK to verify each
step, and hints (try without them). `REQUIREMENTS.md` is the interviewer's
spec — read it first.

Build order: STEP 0–1 in `src/App.jsx` → STEP 2 in
`src/components/Autocomplete.jsx` → STEP 3 in `src/hooks/useDebouncedValue.js`
→ STEPS 4–7 back in the component → STEP 8 in `src/hooks/useSuggestions.js`
→ STEP 9 polish.

Styling is pre-done in `styles.css` (class names documented at the top) —
the exercise is logic and design, not CSS.

```bash
npm install
npm run dev
```

When done: repeat the whole thing later from a BLANK folder with only
`REQUIREMENTS.md`, timed to 75 minutes. That rebuild is what banks it.
