# ShopSmart 🛒 — Learn React Query by Fixing a Bad App

A deliberately badly-written e-commerce app (raw `fetch` + `useState` +
`useEffect` everywhere) backed by the free fake API [dummyjson.com](https://dummyjson.com).

**How to learn:** just read the code. Every problem is marked with a numbered
`📝 TASK` comment explaining what's wrong, why, and how React Query fixes it.
`TASKS.md` is the index. `@tanstack/react-query` is already installed — you
only write the hooks.

```bash
npm install
npm run dev
```
